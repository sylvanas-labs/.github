# Sylvanas Labs

Sylvanas Labs is a private-source software lab building creator tools, automation, and practical desktop/mobile apps.

Most source repositories are private. Public repositories are intentionally used as release and showcase surfaces: installers, APKs, package indexes, changelogs, screenshots, and product notes.

## Public Products

- [Pantheon](https://github.com/sylvanas-labs/pantheon-releases) - creator and agent tooling around Unity, VRChat, Blender, and local development workflows.
- [Karaoke Video Creator](https://github.com/sylvanas-labs/karaoke-video-creator-releases) - Windows desktop pipeline for audio, lyrics, alignment, subtitles, and rendered karaoke video output.
- [VRC Contest Manager](https://github.com/sylvanas-labs/vrc-contest-manager-releases) - local-first desktop tool for hosting VRChat singing contests.
- [Virtual Eden](https://github.com/sylvanas-labs/virtual-eden-releases) - cross-platform app with Android and Windows release channels.
- [Book Scout](https://github.com/sylvanas-labs/book-scout-releases) - desktop release channel for book and library workflow tooling.
- [Disk Scout](https://github.com/sylvanas-labs/disk-scout-releases) - Windows disk analysis and cleanup utility.

## Source Policy

Unless a repository explicitly says otherwise, public Sylvanas Labs repositories contain release artifacts and documentation only. Product source code remains private.
